# Build a Full-Stack PetCare Platform

## 1. Project Overview

Build a modern, production-quality full-stack web application called **PetCare**.

PetCare is an all-in-one pet-care platform combining:

* Pet food e-commerce
* Personalized pet food recommendations
* Recurring food subscriptions
* Veterinary recommendations
* Online veterinary consultations
* Pet health records
* Pet-care reminders
* Order and delivery tracking
* Payments
* AI-powered pet-care assistance
* Admin, veterinarian, vendor, and delivery dashboards

The application should feel like a modern commercial SaaS/e-commerce product, not a basic student CRUD application.

The platform must be responsive and work beautifully on desktop, tablet, and mobile.

# 39. Replit Execution Instructions

Start by analyzing the complete requirements above.

Do not attempt to implement every advanced feature in a single rushed step.

First create the project architecture, database schema, authentication system, and core UI.

Then implement each phase systematically.

After each phase:

1. Run the application.
2. Check for TypeScript errors.
3. Check for backend errors.
4. Test API endpoints.
5. Test database operations.
6. Test authentication.
7. Test role permissions.
8. Fix errors before continuing.
9. Keep the application runnable at every stage.

Do not replace working functionality when implementing new features.

Use reusable components and services instead of duplicating code.

Keep environment variables in `.env` and provide a `.env.example`.

Create a comprehensive `README.md` explaining:

* Installation
* Environment variables
* Database setup
* Prisma migrations
* Seed data
* Running frontend
* Running backend
* Demo accounts
* API structure
* Deployment instructions
